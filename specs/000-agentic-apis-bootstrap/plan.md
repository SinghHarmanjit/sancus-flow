# Implementation Plan: Agentic APIs Bootstrap

**Branch**: `000-agentic-apis-bootstrap` | **Date**: 2026-10-03 | **Spec**: [spec.md](./spec.md)

**Input**: Feature specification from `specs/000-agentic-apis-bootstrap/spec.md`

## Summary

Wire the `agentic-apis` NestJS service from skeleton to fully operational: local LLM models (gemma3 + nomic) reachable via `llm-run`, PostgreSQL connected with Drizzle migrations auto-applied on startup, a `LlmService` providing the `ChatOpenAI` client via NestJS DI, a complete `ChatModule` (controller + service + repository) exposing four REST endpoints, and a health check confirming all systems are live.

---

## Technical Context

**Language/Version**: TypeScript 5.7, Node.js via Bun runtime

**Primary Dependencies**:
- NestJS 12 (`@nestjs/common`, `@nestjs/config`, `@nestjs/core`, `@nestjs/platform-express`)
- Drizzle ORM 0.45.3 (`drizzle-orm`, `drizzle-kit` 0.31.11)
- LangChain OpenAI compat (`@langchain/openai` ^1.6.2)
- PostgreSQL driver (`pg` ^8.23.1, `@types/pg`)
- pgvector (`pgvector` ^0.3.0)
- Zod 4 (`zod` ^4.6.5)
- Class-validator / class-transformer (for NestJS DTOs — to be added)

**Storage**: PostgreSQL 16 + pgvector extension. DB: `tandemlegal` on `127.0.0.1:5432`.

**Testing**: Bun test / Jest (`bun test`). Manual E2E via curl (see `quickstart.md`).

**Target Platform**: Local macOS development → AWS ECS Fargate (production)

**Project Type**: NestJS web service (HTTP REST API)

**Performance Goals**: Server ready < 10s startup. LLM response time is model-dependent (local inference).

**Constraints**: No Prisma. No direct DB access from frontend apps. Drizzle only.

**Scale/Scope**: Single developer, local bootstrap. Supports one domain model (wills + conveyancing).

## Implementation Sequence (for `/speckit-tasks`)

1. Install missing dependencies (`class-validator`, `class-transformer`)
2. Create `drizzle.config.ts`
3. Add `db:generate`, `db:migrate`, `db:studio` scripts to `package.json`
4. Create `DrizzleService` + `DrizzleModule`
5. Create `LlmService` + `LlmModule` (using `getLLM` pattern)
6. Create `ChatRepository` (Drizzle queries)
7. Create `ChatService` (business logic, LLM invocation)
8. Create `ChatController` (DTOs, route handlers)
9. Create `ChatModule`
10. Create `HealthController` + `HealthModule`
11. Update `AppModule` (ConfigModule global, import all modules)
12. Update `main.ts` (global ValidationPipe, CORS, port)
13. Update `.env` to correct LLM ports
14. Generate migrations: `bun run db:generate`
15. E2E validation per `quickstart.md`
